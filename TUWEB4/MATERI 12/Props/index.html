Pembahasan: Props dalam Component

Penjelasan

Props (Properties) adalah cara untuk mengirim data dari parent component ke child component. Props membuat component dapat menerima data eksternal dan menjadi reusable.

Props bersifat read-only dalam child component (immutable). Parent component dapat mengubah nilai props, tetapi child component tidak bisa memodifikasi props secara langsung.

Kita dapat mendefinisikan tipe data, validasi, dan nilai default untuk props.
