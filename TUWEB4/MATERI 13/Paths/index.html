Fasilitas Canvas: Paths

Penjelasan

Paths (Jalur) adalah serangkaian titik yang dihubungkan untuk membentuk bentuk apapun di Canvas. Paths memberikan fleksibilitas lebih dibanding rectangles karena dapat membuat bentuk kompleks dan bebas.

Metode utama untuk membuat paths:

  • beginPath() - Memulai path baru
  • moveTo(x, y) - Memindahkan pen ke titik tertentu
  • lineTo(x, y) - Menarik garis ke titik
  • arc(x, y, radius, startAngle, endAngle) - Membuat busur/lingkaran
  • quadraticCurveTo() - Kurva kuadratik
  • bezierCurveTo() - Kurva Bézier
  • closePath() - Menutup path
  • stroke() - Menggambar outline path
  • fill() - Mengisi path
